# Workflow

## 1. Confirm Scope

Identify goal, audience, inputs, and whether the user wants a draft only or durable writes.

## 2. Collect Facts

Gather only user-provided or tool-retrieved facts. Separate facts from inference.

## 3. Preview

Show structure, gaps, and intended write targets before persisting.

## 4. Persist After Confirmation

Write only after explicit confirmation. Return resource links and remaining open questions.
