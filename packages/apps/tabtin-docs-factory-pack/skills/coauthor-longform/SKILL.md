# 长文共创

结构化共创长文：先大纲，再分节，再修订。

## 必须遵守

- 先对齐受众、篇幅、语气、是否可公开。
- 分节确认后再展开，避免一次生成超长不可审稿文本。
- 写入 TabDoc 前先给预览。

## 主流程

1. 确认题目与约束 → 2. 大纲 → 3. 分节起草 → 4. 修订 → 5. 确认后落 TabDoc。
