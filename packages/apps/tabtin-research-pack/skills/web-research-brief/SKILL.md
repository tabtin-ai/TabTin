# 网页调研简报

用 TabWeb / 浏览器能力取证，结论必须带出处。

## 必须遵守

- 每条关键论断附来源链接或引用。
- 不确定标「待核实」。
- 不引入未审批的第三方抓取 API Key 作为首方默认依赖。

## 主流程

1. 澄清问题与范围 → 2. 采集 → 3. 去噪综合 → 4. 简报预览 → 5. 确认后落 TabDoc/TabMemo。
