# Templates

## Weekly Report

```markdown
# <周期>工作总结：<项目/团队>

## 一句话总结
<本期最重要的结果或变化>

## 本期完成
- <成果>（来源：<source>）

## 关键进展
- <进展>（状态：<进行中/待确认>）

## 风险与阻塞
- <风险>：<影响>；<建议>

## 下期计划
- <计划，不写成已完成>

## 需要支持
- <需要谁做什么决定或提供什么资源>
```

## Management Summary

```markdown
<周期>摘要：

1. <结论 + 影响>
2. <风险 + 需要的支持>
3. <下期重点>

素材覆盖：Memo <N> 条，Doc <N> 篇，表格记录 <N> 条。
未覆盖：<缺失来源>
```

## User Receipt

```markdown
已生成 <周期>工作总结：

- 文档：<tabtin resource link or 草稿>
- 素材来源：<coverage>
- 未覆盖：<missing inputs>
- 待确认：<questions>
```
