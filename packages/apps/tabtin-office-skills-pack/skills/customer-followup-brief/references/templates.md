# Templates

## Customer Brief

```markdown
# 客户跟进简报：<客户名>

## 客户概况
<已知事实，注明来源>

## 最近沟通
- <date/source>: <summary>

## 当前诉求
- <need>

## 风险与阻塞
- <risk + impact + source>

## 我方承诺
- <commitment + owner + due date>

## 下一步建议
- <action + owner + date>

## 邮件/沟通草稿
<optional draft>
```

## Follow-Up Row

```json
{
  "客户": "<customer>",
  "阶段": "<stage or 待确认>",
  "下一步": "<next action>",
  "负责人": "<owner or 待确认>",
  "跟进日期": "<YYYY-MM-DD or 待确认>",
  "风险": "<risk>"
}
```

## User Receipt

```markdown
客户简报已整理：

- 文档：<tabtin resource link or 草稿>
- 下一步：<action + owner + date>
- 风险：<1-3 items>
- 待确认：<gaps>
```
