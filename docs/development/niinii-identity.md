# NiiNii 对话形象

[English](niinii-identity.en.md)

默认对话伙伴和七个内置角色统一使用 NiiNii 名称及小熊猫形象。已有默认 Agent 或保留工厂名称的旧角色，在界面显示时兼容转换；用户自定义名称、头像和几何功能头像保持原样，不需要修改现有数据库。

欢迎标题仍使用原来的排版：`text-display` 字号、`1.25em` 行内头像及原有间距。消息、角色列表、群聊消息和提及选择器沿用各自现有头像尺寸，欢迎形象仍高 `7rem`。点击形象的反馈及输入框聚焦行为保留。

桌面端共享 `niinii-mascot.png`；七个历史头像 key 保持不变，iOS、Android 与角色素材目录中的对应图片同步替换。应用安装图标、工作空间图标和表情贴纸不属于此次 Agent 头像替换。

## 素材来源

NiiNii 小熊猫 PNG 由本次修改的请求者提供，按原始文件字节使用，未重新绘制或修改图片内容。素材著作权及发布授权仍由提供者负责确认。本次修改没有引入外部下载的素材。

## 兼容性

- 已保存的历史消息、Agent ID、头像 key 和用户编辑值不变。
- 手动输入旧名称或 NiiNii 均可提及唯一对应的 Agent；与其他成员重名时不猜测目标，仍可通过选择器插入明确 ID。
- 自定义头像加载失败时，Agent 头像回退到 NiiNii；人类成员与工作空间的头像逻辑不变。
- 移动端仅替换七个历史图片资源，未更改布局或协议；本次未执行 iOS、Android 构建。
