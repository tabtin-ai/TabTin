## [1.1.2] - 2026-08-22

First public source snapshot. The version matches the current hosted product **1.1.2**, so issues, security reports, and client versions can refer to the same number. This repository does not reconstruct private development history; the notes below describe only this public slice.

### Added

- Public repository and GitHub Release: the source snapshot corresponds to product 1.1.2.
- Community local-run path: self-hosted TabTin Server, desktop client, and BYOK model configuration.

### Notes

- Official hosted services, client update channels, and the production backend keep their existing release process. Tags in this repository do not deploy production.
- The community release does not ship official installers or the official auto-update channel. Community builds use the product version fields in this tree.
