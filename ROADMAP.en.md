# TabTin Public Roadmap

[中文](ROADMAP.md)

TabTin is in Public Preview. This roadmap communicates current investment directions rather than fixed release dates or feature commitments. Priorities may change based on real-world feedback, security risk, and engineering verification.

## Now: establish a trustworthy public baseline

- Release the actual product source instead of a separate simplified demo.
- Validate the desktop, full self-hosted, and source-development paths in clean environments.
- Rebuild product, deployment, development, contribution, security, and support documentation in Chinese and English.
- Complete secrets, third-party license, private-link, and brand-asset reviews.
- State the current capabilities, experimental boundaries, and known limitations of each Public Preview component.

## Next: make usage and contribution more reliable

- Improve the reliability and understandability of core collaboration flows based on community feedback.
- Improve self-hosted deployment, upgrade, backup, diagnostics, and operations.
- Strengthen public test entry points, developer documentation, and contribution feedback loops.
- Make validated Agent rules, Skills, and working methods easier to reuse and inspect.

## Later: expand composability

- Make the Agent Runtime and work applications more modular and pluggable.
- Let developers define more data structures, operating surfaces, and Agent capabilities.
- Explore combinations of different Agent runtimes, models, tools, and work applications.
- Continue exploring responsibility, handoff, and acceptance for people and Agents in long-running work and team collaboration.

## How to participate

- Open an Issue for a well-defined problem or request.
- Start a Discussion for an early or open-ended direction.
- Discuss significant design changes before opening a Pull Request.
- Support for a roadmap item does not create a delivery date. Maintainers will identify work that has entered implementation and release verification.

This roadmap is updated when directions materially change, not on an artificial fixed schedule.
